Get started in 3 steps

 

Get a free Groq key

Sign in at console.groq.com/keys, click Create API Key and copy it (starts with gsk_).

Install and paste

Open the app, paste the key, press Test, then Start (Windows) or Save and test key (Android).

Fix any text

PC: press Ctrl + Alt + G. Phone: select text, tap More, then Fix grammar.

Questions

 

Is it really free?

The app is free and open source. Groq offers a free tier for API keys, which is enough for normal use.

Where does my text go?

Only to the Groq API, and only when you press fix. The project has no server and no tracking.

How do I use the 1-tap Fix keyboard?

Enable “Grammar Fixer (1-tap Fix)” in your phone's keyboard settings. Then tap the globe key on Gboard to switch to it. It fixes the text box and returns to Gboard.

Windows says “protected your PC”

The exe is not code-signed yet. Click More info, then Run anyway. You can read and build the full source on GitHub.

Can I change it?

Yes. MIT license. Fork the repo, edit the prompt or model, and rebuild with build.ps1.
